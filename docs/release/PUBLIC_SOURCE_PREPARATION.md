# 公开源码的范围与维护

本项目自研源码通过 [tianyiswl/yijianjifa](https://github.com/tianyiswl/yijianjifa) 按 [MIT](../../LICENSE) 公开。源码公开与 Windows/Mac 程序包发行分别验收；源码仓库不包含新版免费二进制发行包。

## 公开内容

- 桌面客户端、独立云配音服务、数据库迁移与允许公开的测试源码。
- 构建和检查脚本、配置示例及保留原归属的第三方许可文本。
- 项目品牌 SVG、由其生成的图标与专门合成的测试媒体；它们不含用户素材或真实账号数据。

不公开真实数据库、平台会话、供应商密钥、管理配置、用户素材、运营截图、构建产物和私有历史证据。官方音色示例 MP3、识别模型、浏览器及媒体工具二进制不作为源码内容附送。

本仓库采用独立的公开提交历史，不携带原私有仓库历史。公开代码中的合成测试数据不代表真实账号、订单或发布结果。

## 准备工具

`tools/prepare_public_source.py` 可从受信任的 Git 工作区制作本地文本审阅目录：

```sh
python tools/prepare_public_source.py --repo /absolute/path/to/checkout --output /absolute/existing-parent/new-review-directory
```

工具只处理已跟踪文件的当前内容，使用路径与文本类型白名单，不复制 Git 历史或未跟踪文件。输出必须是仓库外的新绝对路径；已有目录和符号链接等危险输入会被拒绝。新文件应逐项审阅后加入 Git index，不能为导出而盲目暂存整个目录。

预检包含 UTF-8 文本、路径安全、高置信度服务令牌和明显配置凭据检查。它不能证明不存在所有敏感信息或权属问题，也不能代替人工复核。工具对媒体与二进制采取保守排除；需要公开的项目资产应另行确认来源和权利、逐项纳入并记录哈希，不能为通过扫描而改名绕过规则。

工具输出的 `release_ready=false` 是准备阶段的保守标记，工具执行成功不会自动批准公开或发行。本次源码公开状态以最终仓库中的实际文件及提交哈希为准；完整二进制交付仍需另行验收。私有排除路径的详细清单留在本地，不用于公开仓库。

## 测试与资产

项目图标可通过 `packaging/generate_icons.py` 从 SVG 再生。能力检测使用固定测试片及其源码中的 SHA-256；更换片段须同步校验值并重新验证，不可删除完整性检查。

没有附送的官方音色示例不得伪造为其他声音。测试应使用明确标记的合成夹具，不把本地系统声音或无声片段称作供应商官方样音。

源码检查、单元测试、完整回归、冻结构建、目标设备验收和真实平台发布为不同验证范围。历史私有验收文档不作为公共仓库的测试输入或“通过”证据。真实平台测试使用有权操作的账号与内容，验证码由账号本人处理；原结果未知时不自动重复提交。
