# 可选云配音服务

本目录提供独立的账号、配音字数、兑换码与生成作业服务源码，适用于自行部署。自研服务代码随项目按 [MIT](../../LICENSE) 公开；供应商服务、音色授权和运行凭据不随源码提供。

桌面软件与系统配音免费，不依赖本服务。云配音是需用户主动登录并选择使用的可选收费功能。源码客户端已提供现有业务入口；自建服务仍可覆盖配置，见[客户端配置说明](../../docs/CONFIGURATION.md)。本目录不是可直接使用的公共云服务承诺。

## 环境与本机开发

需要 Linux/macOS、Python 3.12 或 3.13。服务依赖 `fcntl` 进程锁，Windows 桌面不需要运行它。

从仓库根目录，在独立虚拟环境中安装：

```sh
python -m pip install -e './server/cloud_voice[operator]' 'waitress==3.0.2' 'pytest>=8,<10'
```

指定新的隔离数据库路径后启动本机开发服务。以下路径仅作示例，需自行准备私有目录：

```sh
export YJJF_CLOUD_DATABASE=/absolute/private/cloud-voice-test/voice.db
python -m yijianjifa_cloud_voice --port 8768
```

开发入口只监听回环地址。只配置数据库时可检查账号和兑换流程，未配置供应商的生成接口返回服务未开通；没有内置免费云额度或正式测试账号。

可选本机系统声音模拟入口为 `python -m yijianjifa_cloud_voice.local_test`，需要 macOS 的 `say`、已安装的 Tingting 声音和 FFmpeg。它使用独立测试数据库模拟配音流程，不连接供应商，不代表供应商音色或真实收款。用 `--help` 查看参数，不要指向正式数据库或客户数据目录。

## 供应商配置

| 环境变量 | 用途 |
| --- | --- |
| `YJJF_CLOUD_DATABASE` | 独立 SQLite 数据库绝对路径，必填。 |
| `YJJF_CLOUD_AUDIO_DIR` | 旧同步作业的私有音频目录；新供应商直下载作业不在服务端保存音频。 |
| `YJJF_CLOUD_VOICES_FILE` | 已核准音色 JSON 文件的绝对路径。 |
| `YJJF_VOLC_API_KEY` | 新版供应商 API Key，不与旧版两项混用。 |
| `YJJF_VOLC_APP_ID` | 旧版 App ID，须与下面的 Access Token 同时提供。 |
| `YJJF_VOLC_ACCESS_KEY` | 旧版 Access Token，不是通用 IAM AK/SK。 |
| `YJJF_CLOUD_MAX_DAILY_WORDS` | 每日提交供应商的字数上限，必须为正整数。 |
| `YJJF_CLOUD_TRUSTED_PROXIES` | 明确可信代理 IP 列表；默认不信任任何转发头。 |

允许音色文件为 JSON 列表，元素形如 `{"id":"doubao:approved_voice_id","name":"用户可见名称"}`。先核对账号、模型服务及每个音色的实际权限，名称存在不等于有权使用。

服务端保管供应商密钥，客户端不接收主密钥。客户端配音账号与供应商账号彼此独立。正式价格和兑换规则须向使用者明确说明；当前实现每枚兑换码对应 1 万字，界面价格为 19.9 元/万字，自行部署者应保持前后端规则一致。

## 生成、下载与扣字数

1. 整批先预留新生成所需字数；余额不足时不调用供应商。按实际发送配音的 Unicode 码点计字，包含该文本中的标点、空白等；只作发布资料而未发送配音的内容不计。
2. 供应商异步任务先持久化任务身份，再提交和查询。直下载作业由服务端可信查询确认成功且提供有效下载描述后结算，客户端回执不能决定扣费。明确生成失败释放预留；网络超时、原结果未知时先查询原任务，不自动再次提交。
3. 客户端通过短时供应商链接直接下载，校验后长期保存在本机。新音频不经过本服务落盘，签名下载地址不进数据库或日志；旧同步作业仍使用兼容读取路径。
4. 相同账号、文字、音色和语速能复用本地音频，或能重新下载原音频时，不再次扣字数。配音后剪辑失败也优先复用已有音频。
5. 下载链接过期只触发原任务地址重新获取，不等于音频已清理。只有服务端确认原音频不可恢复并返回 `audio_gone`，客户端才自动走恢复流程；服务端再次核实原状态、可用余额与原尝试号，创建新的生成尝试，按成功字数扣费。余额不足时暂停，充值后继续。
6. 临时网络异常、下载失败、权限问题或未知状态都不作为音频已清理的依据，不会因此自动重生成或重复收费。首次使用说明这一规则，之后不反复弹窗。

供应商的音频保留期和下载地址有效期取决于实际服务版本；不要把某个链接失效或固定天数当作可自动重扣费的证据。不同账号不能读取彼此任务或音频。

## 兑换码和经营管理

本服务不接微信/支付宝自动支付。经营者应先核实外部收款，再发码并通过原购买渠道交付。付款本身不会自动增加字数，每枚码只能兑换一次，已兑换账目不能删除来重新发放。

管理页是独立进程，普通配音用户没有经营权限。购买备注可填写微信昵称或店铺订单号；不同购买可使用相同备注，新的购买使用新的购买标识，同一笔请求重试返回原码，不重复发放。不要把重试当作新的购买。

首次设置管理配置时，使用专用服务身份在安全终端执行，替换以下示例路径和域名：

```sh
python -m yijianjifa_cloud_voice.operator init --database /absolute/private/cloud-voice/voice.db --config /absolute/private/cloud-voice-operator/operator.json --origin https://voice.example.test
python -m yijianjifa_cloud_voice.operator serve --config /absolute/private/cloud-voice-operator/operator.json --port 18771
```

管理密码为 6—50 位，终端输入不回显。配置目录和文件需限制访问；配置包含口令哈希及码加密密钥，须与数据库分别安全备份，不放入源码、静态网站或客户程序包。

管理页登录保持 30 天，关闭浏览器和重启服务后可继续；主动退出立即使相应会话失效。公网访问需要 HTTPS 与正确的 Origin/Host、代理和访问限制。内置 `serve` 只用于本机开发，不能直接暴露公网。

保留的 `admin` 命令可用于受控服务器操作，具体参数见 `python -m yijianjifa_cloud_voice.admin --help`。它与管理页的购买请求接口不同；不要直接改数据库增加余额，也不要把开发测试码交付真实买家。

## 部署与数据保护

WSGI 工厂为 `yijianjifa_cloud_voice.wsgi:create_from_environment`。使用单进程、多线程，绑定回环地址，由反向代理提供 HTTPS。不能让多个进程或副本共享此 SQLite，也不能使用预加载后 fork 的方式绕过进程锁。

数据库、WAL、会话、文案、经营配置及旧同步音频都属于私有数据。使用一致性 SQLite 备份或停服务后的完整备份；不要只复制正在写入的主库，不要删除正在使用的锁文件。恢复后先核对余额、预留字数和原成功作业。

如配置可信代理，代理需覆盖 `X-Real-IP` 为真实直连客户 IP，后端只允许该代理访问；不透传客户伪造的转发头。限制请求体、连接数及来源速率，不记录请求体、Authorization、签名 URL 或密钥。

客户端当前没有找回密码入口，请提醒用户保存账号密码；修改密码和退出会撤销相应会话。遗留兼容恢复能力不应作为默认客户操作流程。

## 隔离测试

从仓库根目录运行：

```sh
PYTHONPATH=server/cloud_voice python -m pytest server/cloud_voice/tests -q
```

测试使用临时数据库、合成账号/兑换码和假供应商，不需要真实密钥或供应商费用。真实供应商生成、真实付款、公网连接和 Windows/Mac 客户端实机验收需分别核对，不能由隔离测试替代。
