# Windows 源码与程序包验收

本仓库公开 0.1.42 源码，软件和系统配音免费，云配音可选收费。当前没有新版免费 Windows 便携程序下载链接。GitHub 的源码 ZIP 不能作为 exe 直接运行；源码启动见[快速开始](../../docs/QUICK_START.md)。

## 源码使用

Windows 10/11 64 位环境需准备 Python 3.12、Python 依赖、Playwright Chromium、FFmpeg 与 ffprobe。用独立数据目录启动，不复用个人资料。系统配音不需要云配音账号或充值；官方示例 MP3 未随源码附送，界面按实际可用资源显示。

云音色文字试听和视频制作需要显式配置服务、登录对应配音账号并具有可用字数。文字试听也可能扣字数。配音音频保存在本机，复用或重取原音频不扣字数；原音频确认无法恢复且确需重生成时按成功字数扣费。网络异常或结果未知不能作为重复生成的依据。

## 制作和发布验收

1. 导入少量有权使用的视频与文案，选择免费的系统配音，制作一条短视频。
2. 检查封面、时长、字幕、声音、嵌入预览与导出；退出后重开，确认测试数据仍在原测试目录。
3. 在账号管理登录测试平台账号，确认账号身份与头像，不把扫码完成等同于身份已验证。
4. 核对账号、标题、正文、话题、声明和时间，只提交明确允许发布的内容；先测一条，再测多账号排队。
5. 分别核对平台后台中的作品和定时时间。软件提交、平台接收、审核和最终公开展示分别记录。
6. 平台要求登录或短信验证时按软件提示处理。输入验证码后点击“确认验证码”；再次获取须等待至少 60 秒的间隔。“关闭”收起验证窗口，可从任务记录继续处理。结果未知时先核对原结果，避免重复投稿。
7. 检查任务删除、失败恢复、取消、断网和重开后的行为；已完成的视频不应重复制作，已接收目标不应自动再次发布。
8. 验证搜索、分类、翻页、素材导入、方案、排期、文件选择和真实鼠标拖放。模拟事件不能替代真实设备上的拖放验收。

系统配音与可选云配音分别验收。云配音真实测试可能产生费用，应使用专门测试账号和明确的测试预算；不要改写真实用户余额或导入他人的账号数据。

## 下载与本地提取

本地视频支持 MP4/MOV/M4V。选择或拖入后，再明确开始处理，核对音频、静音视频、语音字幕、画面字幕及 TXT/SRT 导出。

识别运行时与模型另需准备，锁定输入见 `packaging/recognition-lock.json`。模型不随源码附送，首次识别时明确下载或离线导入。缺少模型应显示准备提示；不能把采样间隔称为识别精度。

## 后续便携包

新版程序包发行前应完成[第三方材料核查](../../docs/release/THIRD_PARTY_RELEASE_READINESS.md)和干净 Windows 设备验收。生成的程序包需记录源码提交号、依赖清单、版本和 SHA-256。

便携包应完整解压后运行，不在压缩包内运行，不单独移动 exe 或删除 `_internal`。应验证中文和空格路径、无额外 Python/浏览器环境的启动、系统配音、预览、制作与发布流程。首次运行的系统安全提示需如实记录，不能要求用户关闭防护。

记录系统版本、CPU、构建提交号、操作步骤和错误提示；任务执行日志可在去除敏感信息后用于反馈。请勿上传 Cookie、会话目录、配音令牌、正式数据库或整个用户数据目录。
